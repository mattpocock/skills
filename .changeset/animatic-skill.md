Add `animatic`, an in-progress model-invoked skill that makes a narrated video of still frames: HTML frames rendered to PNG with Playwright, each line voiced by Kokoro (local, free, no API key), stitched with ffmpeg. It ships a style guide for pacing (Reveals and Cuts, lines written for the ear), a frame kit, a recipe for pull request animatics, and recipes for bringing your own TTS engine, images or visual style.
