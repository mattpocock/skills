Publish the skills to npm as `@mattpocock/skills`. The package ships `skills/` (without `in-progress` and `deprecated`) and `.claude-plugin/`, so tools such as Sandcastle can install a pinned version and read `node_modules/@mattpocock/skills/skills/<category>/<skill>/SKILL.md`, or load the package root as a Claude Code plugin.
